# 🔄 CI/CD & Automation

I believe deployment should be predictable, repeatable, and automated.

```text
Developer
    │
    ▼
   Git
    │
    ▼
  GitHub
    │
    ▼
GitHub Actions
    │
    ├── Lint
    ├── Type Check
    ├── Tests
    ├── Build
    ├── Docker Build
    │
    ▼
 Deployment
    │
    ├── Staging
    │
    ▼
 Production
```

### Typical Pipeline

```text
Pull Request
     ↓
Install Dependencies
     ↓
Lint
     ↓
Type Check
     ↓
Run Tests
     ↓
Build Application
     ↓
Build Docker Image
     ↓
Deploy
```
